# LW Style Engine 0.2

`src/styles/themes.ts` 为视觉 token 的唯一来源，`StyleEngine.tsx` 提供网格、材质底纹与安全区；组件只决定内容与动作。统一 1280×720、30fps，安全间距 80–88px；字号层级为眉题 16–18、主体 26–104（随文本长度自适应）、说明 16–23。中文正文和标题分别按主题使用系统微软雅黑或宋体；未复制第三方字体文件。不同系统缺少相同字体时需重新视觉核验。

| 系统 | Swiss | Future | Archive |
|---|---|---|---|
| 排版 | 无衬线粗标题、严格左对齐 | 无衬线、仪表眉题与信息层 | 宋体/衬线、档案与页码 |
| 网格 | 72px、上下细线、几何角标 | 48px、低对比技术网格 | 64px、双框、程序化纸纹 |
| 间距 | 80px 安全边距 | 80px + 玻璃容器 | 88px + 档案边框 |
| 材质 | 平面、零圆角、无投影 | 24px 圆角、玻璃透色、柔和辉光与投影 | 3px 圆角、纸色底纹与短阴影 |
| 3D | 粗糙哑光、金属度 .08 | 金属度 .78、粗糙度 .22、环境反射 | 金属度 .15、粗糙度 .78、柔和主光 |
| 节奏 | 错峰起点 .07 | 错峰起点 .10 | 错峰起点 .13 |

入场、停留、退场独立输入，合成时长为三者之和；所有运动由 `frame/fps` 决定。标题/图表/扫描光进入、停留后退场；相机入场建立构图，停留期间平滑环绕，最后退场；转场入场和停留保留前画面，退场阶段执行 A→B 并停在完整 B，避免把后画面淡空。

3D 使用真实 Three.js PMREM 程序化室内环境、光照、PBR 材质、阴影和 BokehPass 深度后处理。`useFrame` 只提交后处理渲染，动画、相机与 uniform 仍由 Remotion 帧确定。光圈 0 关闭景深，焦平面/光圈可调。极端缩放下使用 `max(输入半径, 主体缩放×5.7)` 保持安全取景，因此 UI 半径是期望值，极端组合实际半径会增加。

颜色控件显示 `参数颜色 || 当前主题 accent`，与 SVG/Canvas 使用的颜色相同；Three.js 采用同一个基础色，但屏幕像素受环境反射、PBR 光照和色调映射影响，不能要求每个像素等于基础 HEX。

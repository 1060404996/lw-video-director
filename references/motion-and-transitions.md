# 动效、转场与工具选型

优先选择最简单可重复实现：CSS/SVG 处理少量图形；Canvas 处理密集粒子；Remotion 用帧索引与组合时间轴；GSAP 离线渲染时暂停并按帧 seek；Three.js 用于真实空间和摄像机；FFmpeg 用于抽帧、合成及编码。框架 API 和安装版本应查官方资料并本机验证。OpenFilm 仅作待核实候选，不预设真实项目、许可或与参考片的关系。

卡片阵列：统一比例、透视和间距，错峰入场后收束焦点；检查层级和意外裁切。条形图：数值与条长由同一个归一化进度驱动，末值和标尺必须正确。屏幕穿越：屏幕四角、宽高比、透视和交接帧对齐；无法实现 3D 时先验证 2D 推镜，不宣称 3D 已通过。标题、窗口、点阵和画中画均以文字可读、遮挡合理、帧间连续为验收点。转场根据语义选择硬切、叠化、匹配运动或遮罩。

使用统一帧时钟 `t = frame / fps`。设计参数只作试验起点：卡片入场约 0.35–0.65 秒、错峰 0.04–0.10 秒，条形动画约 0.5–0.9 秒，短叠化约 0.15–0.4 秒；根据实际画面调整。渲染后检查入场、中点、末帧和接缝，不把可运行代码视作画面合格。
